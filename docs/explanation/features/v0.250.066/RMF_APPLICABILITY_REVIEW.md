# RMF applicability review

SimpleChat Controls now distinguishes an AI applicability recommendation from
an approved tailoring decision.

- Normal RMF analysis may propose Not Applicable only from affirmative scope
  evidence; missing implementation evidence alone remains a gap.
- A proposal stays `planned` until an Owner or Admin approves it.
- Owners and Admins can approve, reject, directly record, or revoke a
  Not Applicable determination from control detail.
- All members can review the rationale, citations, actor, and immutable history.
- Approved decisions are reused by normal analysis without another model call
  until a manager revokes them.
